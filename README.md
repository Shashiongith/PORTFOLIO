# Portfolio

Vite + Three.js (custom GLSL shader) + GSAP + Lenis. No framework.

    npm install
    npm run dev       # local preview
    npm run build     # outputs dist/ — deploy to Vercel / Netlify / GitHub Pages

## Make it yours
- All text lives in `src/content.js` (search for `TODO`).
- Put your résumé at `public/resume.pdf`.
- Colours per section: `POSES` in `src/scene.js`. Palette: CSS variables at top of `src/style.css`.
